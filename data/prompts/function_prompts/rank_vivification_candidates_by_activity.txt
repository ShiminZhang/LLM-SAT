## 1. FUNCTION CONTRACT

```c
static void rank_vivification_candidates_by_activity (vivifier *vivifier);
```

**Purpose:** Sort the vivifier's `activityrefs` stack to determine the order in which clauses are vivified. Called after `init_activityrefs()` has populated the stack, and before `copy_activityrefs()` extracts the sorted `ref` values.

**Parameter:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `vivifier` | `vivifier *` | Vivification context (see struct below) |

**Contract:** After this function returns, the `vivifier->activityrefs` stack must be in the desired vivification order. The downstream `copy_activityrefs()` iterates the stack front-to-back, extracting `ar.ref` into the schedule.

## 4. SORTING MACROS

### Comparison-based sort (quicksort + insertion sort)
```c

// Sorts stack in-place using a comparator function.
// LESS_THAN(a, b) must return bool: true if a should come before b.
```

The existing comparator `smaller_activity` is defined in vivify.c and available:
