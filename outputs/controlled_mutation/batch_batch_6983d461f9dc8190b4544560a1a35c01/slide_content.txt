============================================================
TEAM LEADER 1: Adaptive Multi-Phase Restarts
============================================================

Step 1: Partition the search into dynamic 'phases' using an activity-based metric: start a new phase whenever the moving average of variable activity over the last 10k conflicts changes by more than 15% compared to the previous phase. Step 2: Within each phase, alternate between three restart strategies: (a) Luby restarts, (b) geometric restarts (base=50, factor=1.5), and (c) no restarts, each for a fixed block of 5,000 conflicts. Step 3: Record the average conflict clause LBD and the reduction in unassigned variables for each strategy block. Step 4: At the end of each phase, select the restart strategy that achieved the best combination of lowest LBD and highest variable reduction for the next phase's dominant strategy (used for 70% of restart blocks, others 15% each). Step 5: If the solver fails to make progress (less than 2% variable reduction in a phase), immediately trigger a rapid sequence of three short Luby restarts (with max length 200 conflicts each) to escape possible stagnation.

============================================================
TEAM LEADER 2: Adaptive Clause-Activity Restarts
============================================================

Step 1: At each conflict, update a moving average of the LBD (Literal Block Distance) of recently learned clauses (window size 50). Step 2: Assign an activity score to each clause based on its recent usage in propagations and conflicts. Step 3: If the moving average LBD drops below a lower threshold (e.g., 3.0), increase the restart interval multiplicatively (e.g., x1.5). If it rises above an upper threshold (e.g., 5.5), decrease the interval (e.g., x0.75). Step 4: Additionally, if the top 10% of clauses by activity contain >20% of the total literals, trigger an immediate restart (diversity trigger). Step 5: After each restart, gradually decay all clause activities to prevent staleness.

============================================================
VARIANTS FOR LEADER 1 (Adaptive Multi-Phase Restarts)
============================================================

--- Variant 1: Trend-Hysteresis Phases ---
Step 1: Partition the search into dynamic 'phases' using a robust trend-and-hysteresis trigger instead of a single activity jump. Maintain (i) an EMA of variable activity with window ~10k conflicts, and (ii) an EMA of LBD with window ~5k conflicts. Start a new phase only if either condition holds for at least 2,000 consecutive conflicts: (A) the activity EMA deviates by >20% from the phase-start baseline AND the sign of the deviation is consistent (monotone trend), or (B) the LBD EMA worsens by >10% while activity EMA improves by <5% (indicating churn without learning quality). Additionally, enforce a minimum phase length of 15k conflicts and a maximum of 80k conflicts; if max is reached, force a phase boundary.
Step 2: Within each phase, alternate between three restart strategies: (a) Luby restarts, (b) geometric restarts (base=50, factor=1.5), and (c) no restarts, each for a fixed block of 5,000 conflicts.
Step 3: Record the average conflict clause LBD and the reduction in unassigned variables for each strategy block.
Step 4: At the end of each phase, select the restart strategy that achieved the best combination of lowest LBD and highest variable reduction for the next phase's dominant strategy (used for 70% of restart blocks, others 15% each).
Step 5: If the solver fails to make progress (less than 2% variable reduction in a phase), immediately trigger a rapid sequence of three short Luby restarts (with max length 200 conflicts each) to escape possible stagnation.

--- Variant 2: Probe-Guided Restart Mixing ---
Step 1: Partition the search into dynamic 'phases' using an activity-based metric: start a new phase whenever the moving average of variable activity over the last 10k conflicts changes by more than 15% compared to the previous phase. Step 2: At the start of each phase, run a short probe of 3 mini-blocks (1,000 conflicts each) using (a) Luby restarts, (b) geometric restarts (base=50, factor=1.5), and (c) ultra-sparse restarts (single restart every 20,000 conflicts; otherwise behave as no-restart). Rank these by a score S = median(LBD) + 0.2*avg(trail_depth) - 0.5*var_reduction. Then schedule the remainder of the phase using an adaptive mixture: 60% of blocks use the top-ranked strategy, 25% use the second, 10% use the third, and 5% are 'shock' blocks of very short Luby (cap 200 conflicts) inserted whenever the last 2,000 conflicts show worsening median(LBD) by >10% or var_reduction <0.3%. Block length is adaptive: start at 5,000 conflicts, but shrink to 2,000 if the last block’s median(LBD) worsens by >10%, and grow to 8,000 if median(LBD) improves by >10% and var_reduction >1%. Step 3: Record the average conflict clause LBD and the reduction in unassigned variables for each strategy block. Step 4: At the end of each phase, select the restart strategy that achieved the best combination of lowest LBD and highest variable reduction for the next phase's dominant strategy (used for 70% of restart blocks, others 15% each). Step 5: If the solver fails to make progress (less than 2% variable reduction in a phase), immediately trigger a rapid sequence of three short Luby restarts (with max length 200 conflicts each) to escape possible stagnation.

============================================================
VARIANTS FOR LEADER 2 (Adaptive Clause-Activity Restarts)
============================================================

--- Variant 1: Robust LBD Trend Restarts ---
Step 1: At each conflict, update a robust, trend-aware estimate of recent learned-clause quality: maintain two EWMAs of LBD (fast and slow) plus an EWMA of LBD dispersion. Winsorize each new LBD by clamping it to [Q10,Q90] estimated online (or equivalently clamp to slow_EWMA ± 2*dispersion_EWMA) before feeding it to the EWMAs. Compute a normalized trend signal T = (fast_EWMA - slow_EWMA) / max(1, dispersion_EWMA). Step 2: Assign an activity score to each clause based on its recent usage in propagations and conflicts. Step 3: Use the trend signal to adapt the restart interval: if T < -0.6 (quality improving), increase the restart interval multiplicatively (e.g., x1.5); if T > +0.6 (quality degrading), decrease the interval (e.g., x0.75). Step 4: Additionally, if the top 10% of clauses by activity contain >20% of the total literals, trigger an immediate restart (diversity trigger). Step 5: After each restart, gradually decay all clause activities to prevent staleness.

--- Variant 2: Tiered Clause Utility Scoring ---
Step 1: At each conflict, update a moving average of the LBD (Literal Block Distance) of recently learned clauses (window size 50). Step 2: Replace single clause-activity with a tiered utility score U(C) that combines (a) propagation usefulness, (b) conflict involvement, (c) recency, and (d) quality normalization by LBD and size: maintain per-clause counters prop_hits (increment when C is the reason of a propagated literal) and conf_hits (increment when C is used in conflict analysis / resolution), and a last_touched conflict index. Every 32 conflicts, update U(C) lazily when touched as: U(C) = (wP*prop_hits + wC*conf_hits) * exp(-(now-last_touched)/tau) / (1 + alpha*(LBD(C)-2) + beta*log2(|C|)). Use two tiers: if LBD(C) <= 3 then multiply U(C) by gamma_good (>1), else multiply by gamma_bad (<1). Reset prop_hits/conf_hits after each periodic update (not on every conflict) to reduce noise. Step 3: If the moving average LBD drops below a lower threshold (e.g., 3.0), increase the restart interval multiplicatively (e.g., x1.5). If it rises above an upper threshold (e.g., 5.5), decrease the interval (e.g., x0.75). Step 4: Additionally, if the top 10% of clauses by utility U contain >20% of the total literals, trigger an immediate restart (diversity trigger). Step 5: After each restart, gradually decay all clause utilities by scaling last_touched forward (or equivalently multiplying U by a constant <1) to prevent staleness.

CODE FOR LEADER 1 (Adaptive Multi-Phase Restarts)

#include <math.h>
#include <stdbool.h>
#include <stdint.h>
#include <inttypes.h>

// Constants for our adaptive multi-phase heuristic
#define AMP_PHASE_WINDOW_CONFLICTS 10000u
#define AMP_BLOCK_CONFLICTS 5000u
#define AMP_NUM_STRATEGIES 3
#define AMP_PHASE_ACTIVITY_THRESH 0.15
#define AMP_DOMINANT_FRAC 0.7
#define AMP_NONDOM_FRAC 0.15
#define AMP_LUBY_BASE 1
#define AMP_GEOM_BASE 50u
#define AMP_GEOM_FACTOR 1.5
#define AMP_LUBY_RAPID_LEN 200u
#define AMP_RAPID_RESTARTS 3
#define AMP_MIN_PROGRESS 0.02

// To be placed at file scope (top of restart.c or in a static file-local section)
typedef struct {
  double prev_phase_activity_avg;
  double curr_phase_activity_sum;
  unsigned curr_phase_activity_cnt;

  // Per-phase tracking
  unsigned phase_start_conflicts;
  unsigned phase_start_unassigned;
  unsigned phase_end_unassigned;

  unsigned block_start_conflicts;
  unsigned block_start_unassigned;
  unsigned block_strategy; // 0=Luby, 1=Geom, 2=None
  unsigned block_index_in_phase;

  // Per-block statistics for all strategies within phase
  struct {
    double sum_lbd;
    unsigned lbd_count;
    unsigned unassigned_start;
    unsigned unassigned_end;
    unsigned blocks;
  } strategy_stats[AMP_NUM_STRATEGIES];

  // Strategy scheduling for next phase
  unsigned dominant_strategy;
  unsigned block_scheduling[AMP_NUM_STRATEGIES*8]; // up to 8 blocks per phase
  unsigned num_blocks_this_phase;

  // Luby sequence state
  unsigned luby_seq_idx;
  unsigned luby_limit;

  // Geometric sequence state
  unsigned geom_block_idx;
  unsigned geom_limit;

  // Rapid Luby restart state
  unsigned rapid_luby_left;
  unsigned rapid_luby_phase_active;
} amp_restart_state;

static amp_restart_state amp_state = {0};

// Helper: Luby sequence generator (1-based)
static unsigned amp_luby(unsigned i) {
  unsigned k;
  for (k = 1; (1u << k) - 1 < i; ++k);
  if (i == (1u << (k-1)))
    return 1u << (k-1);
  return amp_luby(i - (1u << (k-1)) + 1);
}

// Helper: Reset strategy stats for new phase
static void amp_reset_stats(amp_restart_state *st) {
  for (unsigned i = 0; i < AMP_NUM_STRATEGIES; ++i) {
    st->strategy_stats[i].sum_lbd = 0.0;
    st->strategy_stats[i].lbd_count = 0;
    st->strategy_stats[i].unassigned_start = 0;
    st->strategy_stats[i].unassigned_end = 0;
    st->strategy_stats[i].blocks = 0;
  }
}

// Helper: Schedule next phase's strategy order
static void amp_schedule_next_phase(amp_restart_state *st) {
  // Dominant: best (lowest avg LBD, break ties by most variable reduction)
  double best_score = 1e20;
  unsigned best = 0;
  for (unsigned i = 0; i < AMP_NUM_STRATEGIES; ++i) {
    if (!st->strategy_stats[i].blocks) continue;
    double avg_lbd = st->strategy_stats[i].lbd_count
      ? st->strategy_stats[i].sum_lbd / st->strategy_stats[i].lbd_count : 1e9;
    int var_red = (int)st->strategy_stats[i].unassigned_start -
                  (int)st->strategy_stats[i].unassigned_end;
    double score = avg_lbd - 0.001 * var_red; // Lower is better
    if (score < best_score) { best_score = score; best = i; }
  }
  st->dominant_strategy = best;

  // Compute blocks for next phase (8 blocks = 40,000 conflicts max)
  unsigned blocks = AMP_PHASE_WINDOW_CONFLICTS / AMP_BLOCK_CONFLICTS;
  unsigned dom_blocks = (unsigned)(AMP_DOMINANT_FRAC * blocks + 0.5);
  unsigned non_blocks = (blocks - dom_blocks) / (AMP_NUM_STRATEGIES-1);
  unsigned idx = 0;
  for (unsigned i = 0; i < AMP_NUM_STRATEGIES; ++i) {
    unsigned n = (i == best) ? dom_blocks : non_blocks;
    for (unsigned j = 0; j < n; ++j)
      st->block_scheduling[idx++] = i;
  }
  // Fill any remainder with dominant
  while (idx < blocks) st->block_scheduling[idx++] = best;
  st->num_blocks_this_phase = blocks;
}

// Helper: Called at start of each block
static void amp_begin_block(kissat *solver, amp_restart_state *st) {
  st->block_start_conflicts = CONFLICTS;
  st->block_start_unassigned = solver->unassigned;
  // If starting a new phase, record
  if (st->block_index_in_phase == 0) {
    st->phase_start_conflicts = CONFLICTS;
    st->phase_start_unassigned = solver->unassigned;
    st->curr_phase_activity_sum = 0;
    st->curr_phase_activity_cnt = 0;
    amp_reset_stats(st);
  }
  // Strategy for this block
  st->block_strategy =
    (st->block_index_in_phase < st->num_blocks_this_phase)
      ? st->block_scheduling[st->block_index_in_phase]
      : st->dominant_strategy;
  // Setup Luby/Geom state if needed
  if (st->block_strategy == 0) { // Luby
    st->luby_seq_idx = 1;
    st->luby_limit = st->block_start_conflicts + AMP_LUBY_BASE * amp_luby(st->luby_seq_idx);
  } else if (st->block_strategy == 1) { // Geometric
    st->geom_block_idx = 0;
    st->geom_limit = st->block_start_conflicts + AMP_GEOM_BASE;
  }
}

// Helper: Called at end of each block
static void amp_end_block(kissat *solver, amp_restart_state *st) {
  unsigned strat = st->block_strategy;
  st->strategy_stats[strat].unassigned_start += st->block_start_unassigned;
  st->strategy_stats[strat].unassigned_end += solver->unassigned;
  st->strategy_stats[strat].blocks++;
  st->block_index_in_phase++;
}

// Helper: Activity tracking (call at each conflict)
static void amp_track_activity(kissat *solver, amp_restart_state *st) {
  // Use average variable activity as a proxy (sum scores/vars)
  double sum = 0.0;
  for (unsigned v = 0; v < solver->vars; ++v)
    sum += kissat_get_heap_score(kissat_get_scores(solver), v);
  st->curr_phase_activity_sum += sum / solver->vars;
  st->curr_phase_activity_cnt++;
}

// Helper: LBD tracking (called at each learned clause)
static void amp_track_lbd(kissat *solver, amp_restart_state *st, unsigned lbd) {
  unsigned strat = st->block_strategy;
  st->strategy_stats[strat].sum_lbd += lbd;
  st->strategy_stats[strat].lbd_count++;
}

// Helper: Detect phase change (returns true if phase boundary crossed)
static bool amp_phase_change(amp_restart_state *st) {
  if (st->curr_phase_activity_cnt == 0) return false;
  double avg = st->curr_phase_activity_sum / st->curr_phase_activity_cnt;
  double prev = st->prev_phase_activity_avg;
  if (!prev) { st->prev_phase_activity_avg = avg; return false; }
  double delta = fabs(avg - prev) / prev;
  if (delta > AMP_PHASE_ACTIVITY_THRESH) {
    st->prev_phase_activity_avg = avg;
    return true;
  }
  return false;
}

// Helper: Variable reduction in current phase
static double amp_phase_var_reduction(amp_restart_state *st) {
  if (st->phase_start_unassigned == 0) return 1.0;
  int red = (int)st->phase_start_unassigned - (int)st->phase_end_unassigned;
  return (double)red / st->phase_start_unassigned;
}

// Helper: Setup rapid Luby restarts on stagnation
static void amp_trigger_rapid_luby(amp_restart_state *st) {
  st->rapid_luby_left = AMP_RAPID_RESTARTS;
  st->rapid_luby_phase_active = 1;
  st->luby_seq_idx = 1;
  st->luby_limit = CONFLICTS + AMP_LUBY_RAPID_LEN;
}

// Main function
bool kissat_restarting(kissat *solver) {
  // Always require at least 1 unassigned and some decision level
  if (!solver->unassigned || !solver->level) return false;
  if (!GET_OPTION(restart)) return false;

  amp_restart_state *st = &amp_state;

  // If in rapid Luby restart phase (stagnation escape)
  if (st->rapid_luby_phase_active) {
    if (CONFLICTS >= st->luby_limit) {
      // Advance Luby or finish rapid sequence
      if (--st->rapid_luby_left) {
        st->luby_seq_idx++;
        st->luby_limit = CONFLICTS + AMP_LUBY_RAPID_LEN;
        return true;
      } else {
        st->rapid_luby_phase_active = 0;
        // Begin a new block, new phase after stagnation
        st->block_index_in_phase = 0;
        amp_begin_block(solver, st);
      }
    }
    return false;
  }

  // Track activity metric every conflict
  amp_track_activity(solver, st);

  // Check for phase boundary (every block or if phase activity changed)
  unsigned block_confs = CONFLICTS - st->block_start_conflicts;
  bool phase_end = false;
  if (block_confs >= AMP_BLOCK_CONFLICTS) {
    // End of block: record stats
    amp_end_block(solver, st);

    // If phase window completed, or activity changed, start new phase
    unsigned phase_confs = CONFLICTS - st->phase_start_conflicts;
    if (phase_confs >= AMP_PHASE_WINDOW_CONFLICTS || amp_phase_change(st)) {
      phase_end = true;
      st->phase_end_unassigned = solver->unassigned;

      // Analyze phase for progress
      double var_red = amp_phase_var_reduction(st);
      if (var_red < AMP_MIN_PROGRESS) {
        // Stagnation detected: trigger rapid Luby restarts
        amp_trigger_rapid_luby(st);
        return true;
      }

      // Schedule next phase
      amp_schedule_next_phase(st);
      st->block_index_in_phase = 0;
      amp_begin_block(solver, st);
      return false;
    } else {
      // Next block in phase
      amp_begin_block(solver, st);
      return false;
    }
  }

  // Strategy-specific restart logic
  unsigned strat = st->block_strategy;
  if (strat == 0) { // Luby
    if (CONFLICTS >= st->luby_limit) {
      st->luby_seq_idx++;
      st->luby_limit = st->block_start_conflicts + AMP_LUBY_BASE * amp_luby(st->luby_seq_idx);
      return true;
    }
  } else if (strat == 1) { // Geometric
    if (CONFLICTS >= st->geom_limit) {
      st->geom_block_idx++;
      st->geom_limit = st->block_start_conflicts + AMP_GEOM_BASE *
        pow(AMP_GEOM_FACTOR, st->geom_block_idx);
      return true;
    }
  } else if (strat == 2) { // No restarts in this block
    // No restart
    return false;
  }
  return false;
}

// ----- Tracking LBD for clause learning (call from clause learning code) -----
void amp_learned_clause_lbd(kissat *solver, unsigned lbd) {
  amp_restart_state *st = &amp_state;
  amp_track_lbd(solver, st, lbd);
}

CODE FOR LEADER 2 (Adaptive Clause-Activity Restarts)
============================================================

bool kissat_restarting(kissat *solver) {
  // --- Adaptive Clause-Activity Restarts Implementation ---
  // Step 1: Moving average of LBD of learned clauses (window size 50)
  #define LBD_MA_WINDOW 50
  #define LBD_LOWER_THRESHOLD 3.0
  #define LBD_UPPER_THRESHOLD 5.5
  #define LBD_INTERVAL_INC 1.5
  #define LBD_INTERVAL_DEC 0.75

  // Step 2: Clause activity scores based on propagations/conflicts
  #define CLAUSE_ACTIVITY_DECAY 0.95
  #define DIVERSITY_CLAUSE_ACTIVITY_TOP_PCT 10
  #define DIVERSITY_LITERAL_PCT 20

  // Static variables for per-solver tracking
  static double lbd_window[LBD_MA_WINDOW] = {0};
  static unsigned lbd_index = 0;
  static unsigned lbd_count = 0;
  static double lbd_ma = 0.0;
  static uint64_t last_restart_conflicts = 0;
  static double restart_interval = 0;
  static bool initialized = false;

  // For clause activity and diversity
  static double *clause_activity = 0;
  static size_t clause_activity_size = 0;
  static uint64_t *clause_literals = 0; // literal count per clause
  static size_t clause_literals_size = 0;

  // --- Initialization ---
  if (!initialized) {
    restart_interval = GET_OPTION(restartint);
    last_restart_conflicts = CONFLICTS;
    lbd_count = 0;
    lbd_index = 0;
    for (unsigned i = 0; i < LBD_MA_WINDOW; i++) lbd_window[i] = 0.0;
    lbd_ma = 0.0;
    // allocate clause_activity array large enough for all clauses, only once
    if (clause_activity == 0 || clause_activity_size < solver->clauses.size) {
      if (clause_activity) kissat_free(solver, clause_activity, clause_activity_size * sizeof(double));
      clause_activity_size = solver->clauses.size ? solver->clauses.size : 1024;
      clause_activity = (double*) kissat_calloc(solver, clause_activity_size, sizeof(double));
    }
    // allocate literal counter
    if (clause_literals == 0 || clause_literals_size < solver->clauses.size) {
      if (clause_literals) kissat_free(solver, clause_literals, clause_literals_size * sizeof(uint64_t));
      clause_literals_size = solver->clauses.size ? solver->clauses.size : 1024;
      clause_literals = (uint64_t*) kissat_calloc(solver, clause_literals_size, sizeof(uint64_t));
    }
    // initialize activities and literal counts
    for (size_t i = 0; i < clause_activity_size; i++) clause_activity[i] = 0.0;
    for (size_t i = 0; i < clause_literals_size; i++) clause_literals[i] = 0;
    initialized = true;
  }
  // --- End Initialization ---

  // Step 1: Update LBD moving average at each conflict
  if (solver->conflict) {
    // Only update on new learned clause
    // Find LBD of last learned clause. This can be found via solver->last_learned or similar,
    // but as per API, use the 'solver->lbd' or similar per-conflict if available.
    // If not available, skip update.
    unsigned learned_lbd = solver->last_lbd; // assume field exists, else fallback to 0
    if (!learned_lbd && solver->conflict->lbd) learned_lbd = solver->conflict->lbd;
    if (!learned_lbd) learned_lbd = 0; // fallback if not available
    if (learned_lbd) {
      lbd_ma -= lbd_window[lbd_index] / (double)LBD_MA_WINDOW;
      lbd_window[lbd_index] = (double)learned_lbd;
      lbd_ma += lbd_window[lbd_index] / (double)LBD_MA_WINDOW;
      lbd_index = (lbd_index + 1) % LBD_MA_WINDOW;
      if (lbd_count < LBD_MA_WINDOW) lbd_count++;
    }
  }

  // Step 2: Update clause activity for each clause used in recent conflict/propagation
  // We assume that the solver provides a list of recently involved clauses (e.g. last conflict).
  // Since no API is specified, let's use solver->last_involved as array of clause* and solver->last_involved_size.
  // If not available, skip.
  if (solver->last_involved && solver->last_involved_size) {
    for (size_t i = 0; i < solver->last_involved_size; i++) {
      clause *c = solver->last_involved[i];
      if (!c) continue;
      size_t idx = c->idx; // assume clause has unique index, else use i
      // Grow arrays if new clauses are allocated
      if (idx >= clause_activity_size) {
        size_t new_size = clause_activity_size*2;
        if (idx >= new_size) new_size = idx+1;
        clause_activity = (double*) kissat_realloc(solver, clause_activity, clause_activity_size * sizeof(double), new_size * sizeof(double));
        for (size_t j = clause_activity_size; j < new_size; j++) clause_activity[j] = 0.0;
        clause_activity_size = new_size;
      }
      clause_activity[idx] += 1.0; // bump activity
      // Update literal count only if not set
      if (idx >= clause_literals_size) {
        size_t new_size = clause_literals_size*2;
        if (idx >= new_size) new_size = idx+1;
        clause_literals = (uint64_t*) kissat_realloc(solver, clause_literals, clause_literals_size * sizeof(uint64_t), new_size * sizeof(uint64_t));
        for (size_t j = clause_literals_size; j < new_size; j++) clause_literals[j] = 0;
        clause_literals_size = new_size;
      }
      if (!clause_literals[idx]) clause_literals[idx] = c->size;
    }
  }

  // Step 3: Adjust restart interval based on moving average LBD (only every conflict)
  bool restart_due = false;
  if (lbd_count >= LBD_MA_WINDOW) {
    if (lbd_ma < LBD_LOWER_THRESHOLD) {
      restart_interval = restart_interval * LBD_INTERVAL_INC;
      if (restart_interval < 10) restart_interval = 10;
    } else if (lbd_ma > LBD_UPPER_THRESHOLD) {
      restart_interval = restart_interval * LBD_INTERVAL_DEC;
      if (restart_interval < 10) restart_interval = 10;
    }
  }

  // Only restart if enough conflicts since last restart
  if (CONFLICTS - last_restart_conflicts >= (uint64_t)restart_interval) {
    restart_due = true;
  }

  // Step 4: Diversity trigger - top 10% activity clauses contain >20% literals triggers restart
  unsigned num_clauses = solver->clauses.size;
  uint64_t total_literals = 0;
  for (unsigned i = 0; i < num_clauses; i++)
    total_literals += clause_literals[i];

  // Sort clause indices by activity (descending) - use simple selection if N is small
  unsigned top_n = (num_clauses * DIVERSITY_CLAUSE_ACTIVITY_TOP_PCT + 99) / 100;
  if (top_n < 1) top_n = 1;
  if (num_clauses && total_literals) {
    // Build array of <activity, idx>
    typedef struct { double act; unsigned idx; } clause_act_t;
    static clause_act_t *sortbuf = 0;
    static size_t sortbuf_size = 0;
    if (sortbuf_size < num_clauses) {
      if (sortbuf) kissat_free(solver, sortbuf, sortbuf_size * sizeof(clause_act_t));
      sortbuf = (clause_act_t*) kissat_calloc(solver, num_clauses, sizeof(clause_act_t));
      sortbuf_size = num_clauses;
    }
    for (unsigned i = 0; i < num_clauses; i++) {
      sortbuf[i].act = clause_activity[i];
      sortbuf[i].idx = i;
    }
    // Partial selection sort for top_n
    for (unsigned i = 0; i < top_n; i++) {
      unsigned maxj = i;
      for (unsigned j = i+1; j < num_clauses; j++)
        if (sortbuf[j].act > sortbuf[maxj].act)
          maxj = j;
      if (i != maxj) {
        clause_act_t tmp = sortbuf[i];
        sortbuf[i] = sortbuf[maxj];
        sortbuf[maxj] = tmp;
      }
    }
    uint64_t top_literals = 0;
    for (unsigned i = 0; i < top_n; i++)
      top_literals += clause_literals[sortbuf[i].idx];
    if (top_literals * 100 > DIVERSITY_LITERAL_PCT * total_literals) {
      restart_due = true;
    }
  }

  // Step 5: After each restart, decay clause activities
  if (restart_due) {
    for (unsigned i = 0; i < clause_activity_size; i++) {
      clause_activity[i] *= CLAUSE_ACTIVITY_DECAY;
    }
    last_restart_conflicts = CONFLICTS;
  }

  // --- Standard Kissat restart conditions (from baseline) ---
  // Only allow restart if enabled, not at level 0, etc.
  if (!GET_OPTION(restart)) return false;
  if (!solver->level) return false;

  // Return true if our new adaptive restart condition triggers
  return restart_due;
}
