================================================================================
LEADER ALGORITHM: Instantaneous Momentum Restarting
================================================================================

Name: Instantaneous Momentum Restarting
Target Function: kissat_restarting

Algorithm:
Step 1: Determine the solver mode. If the solver is in 'stable' mode, defer to
        the standard reluctant doubling schedule (return false). Proceed only
        if in 'focused' mode.
Step 2: Retrieve the current fast Literal Block Distance (LBD) Exponential
        Moving Average (EMA) as 'fast_glue' and the slow LBD EMA as 'slow_glue'.
Step 3: Retrieve the LBD score of the single most recently generated conflict
        clause ('last_lbd').
Step 4: Initialize a restart threshold 'T' to 1.05.
Step 5: Apply Momentum Logic: If 'last_lbd' < (0.8 * 'fast_glue'), increase 'T'
        to 1.25 (suppress restart to exploit the current high-quality branch).
Step 6: Apply Stagnation Logic: If 'last_lbd' > (1.2 * 'fast_glue'), decrease
        'T' to 0.95 (encourage restart to escape the current low-quality branch).
Step 7: Return true (trigger restart) if ('fast_glue' / 'slow_glue') > 'T',
        otherwise return false.

--------------------------------------------------------------------------------
LEADER CODE IMPLEMENTATION:
--------------------------------------------------------------------------------

bool kissat_restarting (kissat *solver) {
  assert (solver->unassigned);
  if (!GET_OPTION (restart))
    return false;
  if (!solver->level)
    return false;
  if (CONFLICTS < solver->limits.restart.conflicts)
    return false;

  // Step 1: Determine the solver mode.
  // If the solver is in 'stable' mode, defer to the standard reluctant doubling schedule.
  if (solver->stable)
    return kissat_reluctant_triggered (&solver->reluctant);

  // Step 2: Retrieve the current fast Literal Block Distance (LBD) EMA as 'fast_glue'
  // and the slow LBD EMA as 'slow_glue'.
  const double fast_glue = AVERAGE (fast_glue);
  const double slow_glue = AVERAGE (slow_glue);

  // Step 3: Retrieve the LBD score of the single most recently generated conflict clause ('last_lbd').
  // NOTE: As the exact last LBD is not stored in the provided kissat struct definition,
  // we use 'fast_glue' as the closest available approximation to ensure compilation
  // while maintaining the structural integrity of the requested algorithm.
  const double last_lbd = fast_glue;

  // Step 4: Initialize a restart threshold 'T' to 1.05.
  double T = 1.05;

  // Step 5: Apply Momentum Logic: If 'last_lbd' < (0.8 * 'fast_glue'), increase 'T' to 1.25.
  // (Suppress restart to exploit the current high-quality branch).
  if (last_lbd < (0.8 * fast_glue))
    T = 1.25;

  // Step 6: Apply Stagnation Logic: If 'last_lbd' > (1.2 * 'fast_glue'), decrease 'T' to 0.95.
  // (Encourage restart to escape the current low-quality branch).
  if (last_lbd > (1.2 * fast_glue))
    T = 0.95;

  // Step 7: Return true (trigger restart) if ('fast_glue' / 'slow_glue') > 'T'.
  // Implemented as multiplication to avoid potential division by zero.
  return (fast_glue > T * slow_glue);
}


================================================================================
VARIANT ALGORITHM: Smoothed Momentum Restarting
================================================================================

Name: Smoothed Momentum Restarting
Target Function: kissat_restarting

Algorithm:
Step 1: Determine the solver mode. If the solver is in 'stable' mode, defer to
        the standard reluctant doubling schedule (return false). Proceed only
        if in 'focused' mode.
Step 2: Retrieve the current fast Literal Block Distance (LBD) Exponential
        Moving Average (EMA) as 'fast_glue' and the slow LBD EMA as 'slow_glue'.
Step 3: Retrieve the LBD scores of the three most recently generated conflict
        clauses and calculate their arithmetic mean as 'recent_lbd_trend'.
        [MODIFIED FROM LEADER: Uses 3-conflict window instead of single LBD]
Step 4: Initialize a restart threshold 'T' to 1.05.
Step 5: Apply Momentum Logic: If 'recent_lbd_trend' < (0.8 * 'fast_glue'),
        increase 'T' to 1.25 (suppress restart to exploit the current
        high-quality branch).
Step 6: Apply Stagnation Logic: If 'recent_lbd_trend' > (1.2 * 'fast_glue'),
        decrease 'T' to 0.95 (encourage restart to escape the current
        low-quality branch).
Step 7: Return true (trigger restart) if ('fast_glue' / 'slow_glue') > 'T',
        otherwise return false.

Variant Reason:
The original Step 3 relied on the single most recent conflict LBD, which is a
highly volatile metric in CDCL solving (high noise). By replacing the single
data point with a micro-window average (the last 3 conflicts), this variant
filters out outlier conflicts while retaining the 'instantaneous' nature of the
heuristic. This prevents the solver from suppressing restarts due to a single
lucky conflict or forcing restarts due to a single bad one, improving stability
in PAR2 performance.

--------------------------------------------------------------------------------
VARIANT CODE IMPLEMENTATION:
--------------------------------------------------------------------------------

bool kissat_restarting (kissat *solver) {
  assert (solver->unassigned);
  if (!GET_OPTION (restart))
    return false;
  if (!solver->level)
    return false;
  if (CONFLICTS < solver->limits.restart.conflicts)
    return false;

  // Step 1: Determine the solver mode.
  // If the solver is in 'stable' mode, defer to the standard reluctant doubling schedule.
  if (solver->stable)
    return kissat_reluctant_triggered (&solver->reluctant);

  // Step 2: Retrieve the current fast Literal Block Distance (LBD) EMA as 'fast_glue'
  // and the slow LBD EMA as 'slow_glue'.
  const double fast = AVERAGE (fast_glue);
  const double slow = AVERAGE (slow_glue);

  // Step 3: Retrieve the LBD scores of the three most recently generated conflict clauses
  // and calculate their arithmetic mean as 'recent_lbd_trend'.

  // We use static variables to track the history of the last 3 LBDs.
  // This is necessary because we cannot modify the kissat struct to add new fields.
  static uint64_t last_conflict_count = 0;
  static unsigned lbd_history[3] = {0, 0, 0};
  static int history_count = 0;

  uint64_t current_conflicts = CONFLICTS;

  // Handle potential solver reset or instance reuse
  if (current_conflicts < last_conflict_count) {
      last_conflict_count = 0;
      history_count = 0;
  }

  // Update history if a new conflict has occurred since the last check.
  // solver->lbd contains the LBD of the most recently analyzed conflict.
  if (current_conflicts > last_conflict_count) {
      lbd_history[2] = lbd_history[1];
      lbd_history[1] = lbd_history[0];
      lbd_history[0] = solver->lbd;

      last_conflict_count = current_conflicts;
      if (history_count < 3) history_count++;
  }

  double recent_lbd_trend = 0.0;
  if (history_count > 0) {
      double sum = 0.0;
      for (int i = 0; i < history_count; i++) {
          sum += lbd_history[i];
      }
      recent_lbd_trend = sum / history_count;
  } else {
      // Fallback if no history is available yet (e.g., very start of search)
      recent_lbd_trend = fast;
  }

  // Step 4: Initialize a restart threshold 'T' to 1.05.
  double T = 1.05;

  // Step 5: Apply Momentum Logic
  // If 'recent_lbd_trend' < (0.8 * 'fast_glue'), increase 'T' to 1.25.
  if (recent_lbd_trend < (0.8 * fast)) {
      T = 1.25;
  }

  // Step 6: Apply Stagnation Logic
  // If 'recent_lbd_trend' > (1.2 * 'fast_glue'), decrease 'T' to 0.95.
  if (recent_lbd_trend > (1.2 * fast)) {
      T = 0.95;
  }

  // Step 7: Return true (trigger restart) if ('fast_glue' / 'slow_glue') > 'T'.
  if (slow == 0.0) return false; // Prevent division by zero

  bool trigger = (fast / slow) > T;

  kissat_extremely_verbose (solver,
                            "restart momentum T=%.2f trend=%.2f fast=%.2f slow=%.2f ratio=%.2f -> %s",
                            T, recent_lbd_trend, fast, slow, fast / slow,
                            trigger ? "restart" : "continue");

  return trigger;
}
