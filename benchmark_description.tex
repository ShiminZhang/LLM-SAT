\section{Introduction}

We provide benchmark instances from two combinatorial problems: the Van der
Waerden (VDW) problem and integer multiplication verification. Both families
produce instances at the SAT/UNSAT boundary that are challenging for modern
solvers \cite{b1,b2}. The benchmark list is given in Table~\ref{tab:benchmarks}.

\section{The Van der Waerden Problem}

Van der Waerden's theorem \cite{b3} states that for any $k \geq 1$ and positive
integers $\ell_1, \ldots, \ell_k$, there exists a threshold $W(k;\ell_1,\ldots,\ell_k)$
such that every $k$-coloring of $\{1,\ldots,n\}$ with $n \geq W$ contains a
monochromatic arithmetic progression of length $\ell_i$ in color $i$ for some $i$.
Determining exact Van der Waerden numbers has been a prominent benchmark problem
in SAT solving \cite{b4}.

Instances are generated using the VDW encoder of Bright \cite{b6}, which encodes
the question ``Can we $k$-color $\{1,\ldots,n\}$ without monochromatic
arithmetic progressions of lengths $\ell_1,\ldots,\ell_k$?'' as a CNF formula.
Variable $x_{i,c}$ indicates that position $i$ receives color $c$.
The encoding consists of three types of clauses:
\begin{itemize}
  \item At-least-one-color per position: $\bigvee_c x_{i,c}$ for each $i$.
  \item At-most-one-color per position: $\neg x_{i,c_1} \vee \neg x_{i,c_2}$
        for each $i$ and $c_1 < c_2$.
  \item No monochromatic AP: for each color $c$, step $d$, and start $a$
        with $a + (\ell_c-1)d \leq n$, the clause
        $\neg x_{a,c} \vee \cdots \vee \neg x_{a+(\ell_c-1)d,\,c}$.
\end{itemize}
Instances are selected at and just below known thresholds, so that each
satisfiable instance is paired with an unsatisfiable one at $n = W$.

\section{The Integer Multiplication Problem}

The integer factorization problem---given $N$, find $a, b > 1$ with $a \cdot b = N$---provides
a natural source of hard SAT instances \cite{b2}: satisfiable when $N$ is composite
and unsatisfiable when $N$ is prime.

Instances are generated using the BMC-based multiplication encoder of Li et al.\ \cite{b7},
which encodes $n$-bit unsigned multiplication via a Tseitin transformation \cite{b5}
of a schoolbook partial-product multiplier. Input bits $a_0,\ldots,a_{n-1}$ and
$b_0,\ldots,b_{n-1}$ are the free variables. The encoding consists of:
\begin{itemize}
  \item AND Tseitin gates for each partial product $pp_{i,j} = a_i \wedge b_j$.
  \item Half-adder and full-adder Tseitin gates reducing partial products
        column-by-column into product bits $p_0,\ldots,p_{2n-1}$.
  \item Unit clauses fixing $p_0,\ldots,p_{2n-1}$ to the binary representation of $N$.
  \item Non-triviality clauses enforcing $a > 1$ and $b > 1$.
\end{itemize}
Instances span four bit-widths; UNSAT instances use prime targets and
SAT instances use perfect squares of primes so both factors are exactly $n$-bit.

\section{Benchmarks}

The submitted instances range from easy to hard. Van der Waerden instances
are denoted $\mathrm{VDW}(\ell_1, \ell_2, n)$ where $\ell_1, \ell_2$ are the
AP lengths and $n$ is the domain size. Multiplication instances are denoted
$\mathrm{Mult}(n, N)$ where $n$ is the bit-width of each factor and $N$ is
the target product.
