## 1. FUNCTION CONTRACT

```c
int kissat_set_configuration (kissat *solver, const char *name);
```

**Purpose:** Apply a named configuration to the solver by setting a combination of options. Called from:
- Command-line parsing (`--configname` argument)
- Instance prediction (`predict.c`): calls with `"sat"` or `"unsat"` based on predicted instance type

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `solver` | `kissat *` | Solver instance |
| `name` | `const char *` | Configuration name string |

**Return value:**
- `1` if `name` matched a valid configuration (options were applied)
- `0` if `name` is not recognized

**Required configurations:** The function MUST handle at least `"basic"`, `"default"`, `"plain"`, `"sat"`, and `"unsat"` as valid names. `"default"` must return 1 without changing anything. The `kissat_has_configuration()` function (defined separately in config.c, not replaced) validates names, so your set of handled names should match.

int kissat_has_configuration (const char *name) {
  if (!strcmp (name, "basic"))
    return 1;

    return 1;
  if (!strcmp (name, "plain"))
    return 1;
  if (!strcmp (name, "sat"))

void kissat_configuration_usage (void) {

  kissat_set_option (solver, "bumpreasons", 0);
  kissat_set_option (solver, "chrono", 0);
  kissat_set_option (solver, "compact", 0);
  kissat_set_option (solver, "eagersubsume", 0);
  kissat_set_option (solver, "jumpreasons", 0);

  kissat_set_option (solver, "stable", 2);
  kissat_set_option (solver, "tumble", 0);
}

int kissat_set_configuration (kissat *solver, const char *name) {
  if (!strcmp (name, "basic")) {
    set_plain_options (solver);
    kissat_set_option (solver, "restart", 0);
    kissat_set_option (solver, "reduce", 0);
    kissat_set_option (solver, "minimize", 0);
    return 1;
  }
  if (!strcmp (name, "default"))
    return 1;
  if (!strcmp (name, "plain")) {
    set_plain_options (solver);
    return 1;
  }
  if (!strcmp (name, "sat")) {
    kissat_set_option (solver, "target", TARGET_SAT);
    kissat_set_option (solver, "restartint", RESTARTINT_SAT);
    if (kissat_get_option (solver, "aggressive")) {
      kissat_set_option (solver, "congruenceandarity", 5000000);
      kissat_set_option (solver, "congruencexorarity", 8);
      kissat_set_option (solver, "fastelclslim", 1000);
      kissat_set_option (solver, "reorderint", 2000);
      kissat_set_option (solver, "restartint", 128);
      kissat_set_option (solver, "smallclauses", 1000000);
    }
    return 1;
  }
  if (!strcmp (name, "unsat")) {
    kissat_set_option (solver, "stable", STABLE_UNSAT);
    if (kissat_get_option (solver, "aggressive")) {
      kissat_set_option (solver, "congruenceandarity", 5000000);
      kissat_set_option (solver, "congruencexorarity", 16);
      kissat_set_option (solver, "fastelclslim", 1000);
      kissat_set_option (solver, "reorderint", 50000);
      kissat_set_option (solver, "restartint", 3);
      kissat_set_option (solver, "smallclauses", 1000000);
    }
    return 1;
  }
  return 0;
}
