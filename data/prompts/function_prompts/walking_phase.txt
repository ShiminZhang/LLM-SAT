## 1. FUNCTION CONTRACT

```c
static void walking_phase (kissat *solver, bool first_time, bool use_previous_phase);
```

**Purpose:** Execute one round of local search (SLS / WalkSAT-style). This is the core walking entry point that orchestrates: enter dense mode → initialize walker → run local search → save results → clean up → resume sparse mode.

**Parameters:**
| Parameter | Type | Description |
|-----------|------|-------------|
| `solver` | `kissat *` | Solver instance |
| `first_time` | `bool` | True if this is the first walk (affects minimum saving behavior) |
| `use_previous_phase` | `bool` | True to initialize walk from previously saved phases |

**Caller context:** Called from `walk()` (static in walk.c), which is called from `kissat_walk()` (public). The walk is bracketed by `STOP_SEARCH_AND_START_SIMPLIFIER` / `STOP_SIMPLIFIER_AND_RESUME_SEARCH` in the caller.

```c
struct walker {
  kissat *solver;

  unsigned clauses;        // Number of clauses tracked
```

### Walker lifecycle
```c
init_walker(solver, &walker, &irredundant, use_previous_phase);
// Initializes walker struct: allocates counters, refs, scores table,
// sets up initial variable assignment, counts unsatisfied clauses.
// Parameters: solver, walker pointer, binary clauses, use_previous_phase flag.

init_walker_limit(solver, &walker);
// Sets the step limit for local search based on walkeffort option.
// Initializes walker->limit, walker->flipped, reporting state.

local_search_round(&walker);
// Runs the main local search loop: repeatedly flips variables to reduce
// unsatisfied clause count until limit reached or all clauses satisfied.
// Updates walker->minimum, walker->flipped, walker->current.

save_final_minimum(&walker, first_time);
// Saves the best assignment found during the walk back to solver phases.
// If no improvement and not first_time, keeps existing saved phases.

release_walker(&walker);
// Frees all walker-allocated memory, restores solver->values.
```

## 8. CRITICAL RULES

### Lifecycle Ordering
The dense mode / walker lifecycle MUST follow this order:
1. `INC(walks)` — count the walk
2. Initialize stacks: `INIT_STACK(irredundant)`, `INIT_STACK(redundant)`
3. `kissat_enter_dense_mode(solver, &irredundant, &redundant)` — enter dense mode
4. `init_walker(solver, &walker, &irredundant, use_previous_phase)` — init walker
5. `init_walker_limit(solver, &walker)` — set step limit
6. `local_search_round(&walker)` — run search
7. `save_final_minimum(&walker, first_time)` — save results
8. `release_walker(&walker)` — free walker memory
9. `kissat_resume_sparse_mode(solver, false, &irredundant, &redundant)` — restore sparse mode
10. `RELEASE_STACK(irredundant)`, `RELEASE_STACK(redundant)` — free stacks

**WARNING:** Skipping steps or reordering will corrupt solver state or leak memory. Dense mode MUST be entered before walker init and resumed after walker release.

### What NOT to do
1. **DO NOT invent solver fields** -- only use fields documented above
2. **DO NOT create `kissat_*` prefixed variables** -- reserved for API functions
3. **DO NOT skip `kissat_enter_dense_mode` / `kissat_resume_sparse_mode`** -- walker requires dense mode
4. **DO NOT skip `release_walker`** -- will leak memory and corrupt solver->values
5. **`<string.h>` IS available**
6. **`<math.h>` is NOT included** in walk.c
